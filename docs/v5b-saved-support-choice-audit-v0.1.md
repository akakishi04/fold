The conditional calculation uses the unordered known fact set as an oracle. It preserves original
full predictions and never replaces a production decoder or any masked/full capability gate.
A conditional improvement is not an achieved model improvement. Exact ties are shown and resolved
by numeric class order,not a target-first tie rule. All15 models and complete original data remain.

loss of the final training minibatch. This provides numerical evidence about support mass versus
conditional choice without assuming the model internally implements two separate stages.
