# V5-B byte evaluation contract v0.1

## Purpose after C230

The numeric-memory optimization track is paused. C230 established a useful opt-in preparation
reuse, but not general speed superiority. See docs/experiment-ledger-addendum-c230-c231.md.

Before measuring language ability or scheduling larger training, C231 checks the evaluation
instrument for the existing uncompressed V5-B byte model. It is not a new language model, a
training run, the final v0.5 stack, or progression to V5-G while Gate F is open.

## Model identity

Use `fold_lm/v05/language_task.py:ShortByteLanguageModel`: byte embedding, causal GRU front-end,
uncompressed HighPrecisionFixedRoutingCore and byte decoder. Configuration:48 slots, width16,
2 routed modules,2 internal steps, hidden multiplier2. The resulting instrument has13488 parameters.
Routing is fixed TASK_NEXT=0; it is not inferred from the input. The older
`fold_lm/model.py:FoldLanguageModel` is a different vertical slice and is not substituted here.
The C216-C230 learned H1/H2 components and prepared numeric serving path are not connected by C231.

Instantiate three untrained instruments with seeds231001/231002/231003. CPU float64, threads2,
deterministic algorithms. Do not load a previous scientific model or train/update any parameters.
Random-model scores are instrument outputs, not evidence of meaningful language ability.

## Prefix-only evaluation

For document bytes x and position i, supply:

```text
BOS, x[:i], EOS, PAD...
```

The target x[i] is held separately and is never an argument of the model call. EOS here marks the
end of the observed prefix, not a predicted future document ending. This adapts the existing
fixed-slot model's EOS pooling; it is not an ordinary uninterrupted token-stream LM convention.
Partial Japanese UTF-8 prefixes stay as bytes and are never decoded or silently truncated.

The decoder predicts256 real byte values. PAD/BOS/EOS are neither targets nor generated classes.
Compute per-byte negative log likelihood and bits per byte; sum over bytes rather than averaging
per-document means. Validate cross-entropy against logsumexp minus the gathered target logit.
Uniform256-way logits must yield8 bits per byte. No target NLL or generation-quality threshold is
required for audit PASS.

## Instrument checks

For every document and seed:

- batched prefix logits match singleton-prefix logits within1e-9;
- mutate the latter half of a document: logits through the first changed target position stay
  unchanged because those inputs contain no changed byte;
- the two likelihood calculations agree within1e-9;
- weights remain unchanged;
- serialize and reload the instrument, reproduce logits within1e-9 and reproduce greedy bytes.

Generate four bytes from the first eight observed bytes of each document. Each following prefix
contains the model's own generated bytes, not the reference suffix. Output hex so invalid UTF-8 is
not replaced or confused with fluent language. Fixed short generation is a mechanics test only.

Initial per-document forwards:1 batched score + one singleton per target byte +1 suffix control
+4 generation calls. Reload phase:1 batched score +4 generation calls. Across82 fixture bytes and
four documents this is126 forwards per seed and378 total, measured with forward hooks.
There are246 scored target positions,3 new untrained instrument checkpoints and0 training steps.

Store only under ignored runs/: evaluation-plan.json, byte-fixture.json, untrained-models.pt,
